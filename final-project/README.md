# MathNet CNN: Math Problem Topic Classification

This final project uses the [ShadenA/MathNet](https://huggingface.co/datasets/ShadenA/MathNet) dataset to classify olympiad-style math problems by topic from their problem text. The notebook trains and compares two TensorFlow/Keras text models:

- A 1D convolutional neural network (CNN)
- A lightweight Transformer encoder

The best model in the notebook run was the Transformer, which reached **84.96% best validation accuracy**. The saved inference function currently uses the 1D CNN model, which reached **79.59% best validation accuracy**.

## Dataset

The notebook loads all parquet files from:

```text
MathNet/data/all/train-*.parquet
```

Run summary:

| Item | Value |
|---|---:|
| Parquet files loaded | 56 |
| Total rows loaded | 27,817 |
| Columns | `id`, `problem_markdown`, `solutions_markdown`, `images`, `country`, `competition`, `topics_flat`, `language`, `problem_type`, `final_answer` |
| Rows used after label filtering | 27,231 |
| Train split | 21,784 |
| Validation split | 5,447 |
| Sequence length | 256 tokens |
| Vocabulary size | 20,000 words |

The original dataset has many detailed hierarchical labels in `topics_flat`. For this project, labels were mapped into four broad topic classes:

| Class | Samples |
|---|---:|
| Geometry | 8,313 |
| Algebra | 7,859 |
| Combinatorics | 5,864 |
| Number Theory | 5,195 |

Rare or unmapped categories such as Statistics, Calculus, Precalculus, and Math Word Problems were removed because together they had fewer than 600 examples.

## Model Results

| Model | Parameters | Best Validation Accuracy |
|---|---:|---:|
| 1D CNN text model | 3,668,292 | 79.59% |
| Transformer text model | 2,841,988 | 84.96% |

The Transformer performed best overall, with fewer parameters and higher validation accuracy. The CNN was still saved for inference at the end of the notebook.

Geometry was the strongest class for the CNN, with a 0.92 F1-score. Combinatorics had good precision but lower recall, meaning the model was more conservative about assigning that label. Number Theory had high recall but lower precision, so some non-number-theory problems were predicted as Number Theory.

## Conclusion

This project shows that problem text alone contains enough information to classify math problems into broad topics with useful accuracy. The Transformer encoder gave the strongest result at **84.96% validation accuracy**, while the saved 1D CNN model achieved **79.59% best validation accuracy** and about **80% validation accuracy** in the classification report.

Future improvements could include saving the Transformer as the primary inference model, adding more balanced training data for rare categories, and combining problem text with image features from diagrams.
